本地依赖已缓存，因此运行以上 Go 命令时设置了 `GOPROXY=off`；新环境应先正常下载依赖。所有模型响应使用本地模拟或固定用例，没有调用收费模型。

故障负载复现命令：

```sh
go run ./cmd/gopherharness-loadtest \
  --requests 200 --concurrency 16 --sessions 16 \
  --cancel-every 10 --fail-every 17 \
  --artifact artifacts/offline-load-completion.json
```

`make benchmark` 写出 `artifacts/go-benchmark.json`。负载命令写出配置、结果分类、延迟分位数、活动调用和回收检查。`artifacts/` 不入库；CI 会上传基准报告供下载。

负载中的错误是故障注入结果，不是 200 个真实模型任务的成功率；本轮测试不能证明生产持续吞吐、真实模型效果或真实模型容量。
