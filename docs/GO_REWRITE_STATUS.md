# 能力状态与边界

此清单区分可运行入口、可供 Go 程序接入的模块和后续工作。接口存在不等于所有部署场景已验收，离线回归不等于真实模型效果。

## 已接通的入口

| 入口 | 执行链路 | 默认权限 |
| --- | --- | --- |
| CLI / TUI | app → Agent.Ask → 上下文 → 模型 → 工具 → 回填 → 记录 | 本地审批策略；沙箱需显式配置 |
| 飞书长连接 / HTTP 回调 | gatewayapp → feishu → gateway → scheduler → runtime.Service → delivery | 发送者白名单；默认只开放读取、目录和搜索 |
| 离线回归 | evaluation → 独立 fixture → 固定模型响应 → 运行报告 → 独立 verifier | 按任务指定工具，不访问模型 API |
| 离线负载 | 多会话请求 → 调度器 → 模拟模型 → 结果统计与关闭检查 | 不访问模型 API，独立临时工作区 |
| 候选维护 | 固定基线 → 训练比较 → 唯一候选 → 未见验证 → 人工激活 | 明确授权校验命令；不自动提交、推送或部署 |

飞书提供官方 SDK 长连接接收与加密 HTTP 回调两种事件入口，接入发送者白名单、群提及、媒体大小限制、回复路由、稳定发送标识和持久收发记录。HTTP 回调另有验签和时间检查。本地测试使用模拟平台，尚未进行真实应用、真实群聊或公网部署验收。

## 核心模块

- 调度：同会话顺序、前后台独立容量、追加/注入/打断、结果句柄、取消和关闭封口。Service 会话队列及注入合计 128 条硬上限，50 条深度告警；直接 CLI 不经过多会话调度器。
- 子任务：独立会话、默认并发 4、滚动一小时创建 30 次、跟进 inbox 50 条；登记和完成 receipt 持久保存，管理器持 OS 独占租约。安全点先将稳定消息 ID 写会话再确认，服务空闲时同 lane 后台无工具汇总（最多 2 次模型调用）；摘要生成意图和待发状态可恢复，不为补通知重跑模型或工具。CLI 在下一次 Ask 合并结果，停止会话撤销未发通知；进程重启将孤儿执行标为 interrupted。默认禁止风险写，显式 allow-worker-writes 要求主任务 Auto；Workspace.View 共享仓库和路径锁，不是自动 worktree 隔离。
- 异步审批：工具参数、工具定义和文件前置条件冻结后暂停原批次；批准后再校验并单次 Claim。等待释放容量、同会话普通请求暂停；approved 尚未 Claim 可以拒绝撤回，claimed 未知必须对账。没有审批通知 outbox 或自动同意扫描器，使用显式控制面和 PendingApprovals 查询。
- 上下文：窗口跟随 provider 配置，缺省 65,536 / 输出 8,192；固定材料、原生工具 Schema、当前请求先占位，历史六成触发管理。Curator 最多 12 步、30 秒，具备预算检查、历史查找/读取、脱敏归档/取回、评分和工作状态；失败规则回退。头 6 条消息覆盖的完整组与最新组硬保护，所有路径复算完整输入。每 Turn 完整组装一次，Iteration 增量追加；原生请求超窗可缩减旧工具正文，保留最新 3 条结果，服务端超窗最多 2 次有变化的补救检查。子任务继承、备用模型取最小窗口；本地编码仍是估算，固定材料放不下就失败。见 [上下文设计](CONTEXT_BUDGET.md)。
- 工具：JSON Schema 参数校验、批量原子注册、安全读取并发、写操作屏障、原序回填、批次取消和等待。MCP 使用官方 Go SDK，支持 stdio、SSE、Streamable HTTP；远端声明不自动获得并发权限。
- 会话与恢复：快照、事件、检查点、运行报告；写入有文件锁、所有者代际与内容修订校验。工作区指纹包含路径、类型、权限和内容摘要，可识别同大小同修改时间的正文变化。不复活进程、不自动重放未知副作用；内容读取失败也不能当作指纹一致。
- 记忆：宿主 user.md 与后端查询召回两路合成一个记忆段；宿主选最多 2 个正分章节加 Notes，后端默认最多 5 条，启用后的硬错误中止本轮。配置可接项目 JSON v1 外部后端，完成后材料用持久 Outbox 异步写入；dream 仅处理相同用户会话。工作状态单独承载。事实含仓库/用户范围、来源和版本；同权威冲突仍依提交顺序，不是完整语义裁决。宿主资料由调用者维护，外部服务仍需独立部署与验收。
- 技能：本地 BM25 Okapi，1.5/0.75 参数、名称两次/描述/正文前 4,000 字符索引；常驻最多 5 份、候选最多 5 份、明确激活正文最多 2 份，其余引用通过获准的 skill_read 读取。调用时按 1 秒节流懒刷新并原子发布元数据与索引快照，不是固定 16,000 字节截断；不是后台文件监控、远端源或大模型门控。飞书工具允许名单未因此扩大。
- 模型：OpenAI Responses / Anthropic Messages 原生消息和工具协议，保留推理字段；旧文本协议兼容。配置与 CLI 接通有界重试、备用 provider、迭代上限和显式价格；流式片段已输出后不透明重试。并未根据任务难度自动选择最便宜模型。
- 计量与准入：普通、流式、原生聊天、原生流式及独立视觉调用逐次计量。共享持久预算在发送前预留，每次重试独立算账；完整用量按四类价格结算，未知用量保留占用。崩溃恢复不抢占活动尝试、不假退款；支持人工对账。未知价格冻结准入，不能用账本存在证明已降低成本。见 [费用预算](COST_BUDGET.md)。
- 执行隔离：可配置 OS 沙箱、工作区只读和 Shell 网络禁用，required 或网络禁用要求隔离后端可用；超时/取消终止进程组并等待回收，输出有界捕获。没有 cgroup CPU/内存/进程配额，也不把工具权限检查当系统级隔离。
- 追踪：随机链路/阶段标识，通过 context.Context 显式传递；运行、模型和工具阶段持久记录。子任务、记忆待办和渠道传递/保存身份，但身份关联不等于所有队列和后台生命周期均有完整持久 Span。
- 收发：Inbox/Outbox（收件/待发记录）原子结算、单机文件锁和所有者代际校验。重启仅重排明确未启动工作和未发送结果；运行中任务转待对账，发送中结果转未知。不是跨主机共识或无限期恰好一次投递。
- 维护：问题登记/修复 Go 接口，加 `gopherharness-maintain` 命令。固定训练与未见契约、候选与校验独立工作树、候选/命令次数/超时预算、拒绝训练退化与未见失败、手动激活和版本回滚均有本地测试。命令不自动调用模型、提交或合并；未实现自动线上探索与统计显著性筛选。见 [维护说明](MAINTENANCE.md)。
- 评测：原有 20 个确定性回归任务保留；新增本地 SWE-bench JSONL、Terminal-Bench/Harbor 任务导入、官方补丁格式导出与官方结果文件校验。导入只生成清单/checkout 计划，不执行数据集脚本，不把导入成功当官方测试通过。另有离线 Mock 负载报告，不代表真实模型容量。

## 后续工作

1. 各供应商原生精确计数适配，避免把项目编码估算当真实计费分词。
2. 外部记忆服务的实际部署验收、中文语义召回质量与事实冲突语义判定；通用 JSON 协议不等于已兼容任意记忆产品。
3. 所有跨服务链路的部署级关联、缓存策略收益实验、供应商账单核对。
4. 日志保留/压缩和跨主机主备；当前文件锁与租约是单机协调，不是分布式共识。
5. 自动线上候选探索和统计显著性筛选；目前交付的是本地有限候选、独立验证、人工激活闭环。
6. 公开任务的官方环境实际执行、真实模型成本/时延与持续容量实验、真实飞书应用验收。
