# 能力状态与边界

此清单区分可运行入口、可供 Go 程序接入的模块和后续工作。接口存在不等于所有部署场景已验收，离线回归不等于真实模型效果。

## 已接通的入口

| 入口 | 执行链路 | 默认权限 |
| --- | --- | --- |
| CLI / TUI | app → Agent.Ask → 上下文 → 模型 → 工具 → 回填 → 记录 | 本地审批策略；沙箱需显式配置 |
| 飞书 HTTP | gatewayapp → feishu → gateway → scheduler → runtime.Service → delivery | 发送者白名单；只开放读取、目录和搜索 |
| 离线回归 | evaluation → 独立 fixture → 固定模型响应 → 运行报告 → 独立 verifier | 按任务指定工具，不访问模型 API |

飞书已接入加密事件验签、时间检查、群提及、媒体大小限制、回复路由、稳定发送标识和持久收发记录。本地测试使用模拟平台，尚未进行真实应用、真实群聊或公网部署验收。

## 核心模块

- 调度：同会话顺序、前后台独立容量、追加/注入/打断、结果句柄、取消和关闭封口。直接 CLI 不经过多会话调度器。
- 上下文：按用户轮次分组、首组和最近组保护、词法筛选或可选模型选择、非法计划回退、工具调用/结果标识闭包、完整提示字节上限。不是精确词元计量，没有完整供应商窗口溢出重组循环。
- 工具：JSON Schema 参数校验、批量原子注册、安全读取并发、写操作屏障、原序回填、批次取消和等待。MCP 使用官方 Go SDK，支持 stdio、SSE、Streamable HTTP；远端声明不自动获得并发权限。
- 会话与恢复：快照、事件、检查点、运行报告；恢复比较结构和工作区指纹。不复活进程、不自动重放未知副作用。当前指纹是路径、大小和修改时间，不是完整内容哈希。
- 记忆：独立工作记忆、笔记、可选事实提取；事实含仓库/用户作用域、来源、版本和待确认/生效/替代/失效状态，用版本比较提交。来源引用不等于语义证明；同权威冲突依提交顺序，尚非完整事实真伪裁决。
- 模型：两类兼容协议；Go 接口可配置有界重试和备用客户端；流式片段已输出后不透明重试。重试、价格和高级模型选择还没有统一 CLI 配置入口。
- 计量：逐次普通/流式调用、用量完整性、缓存计量归一化、显式价格估算、异步账本和健康快照。未知用量/价格保持未知；账本本身不保证降低成本。独立视觉接口的所有路径尚未统一覆盖。
- 追踪：随机链路/阶段标识，通过 context.Context 显式传递；运行、模型和工具阶段持久记录。并非所有队列、记忆、子任务和渠道重放路径都已完整关联。
- 收发：Inbox/Outbox（收件/待发记录）原子结算、单机文件锁和所有者代际校验。重启仅重排明确未启动工作和未发送结果；运行中任务转待对账，发送中结果转未知。不是跨主机共识或无限期恰好一次投递。
- 维护：问题登记接口、独立修复工作树、补丁和验证工作树，已有本地测试。尚无 CLI /issue、/fix 命令或通用平台配置，不自动提交或合并。

6. 公开数据集独立适配与官方验收；真实模型成本/时延实验。
