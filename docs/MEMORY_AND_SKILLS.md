# 记忆与技能：固定职责，不混用通道

## 记忆只有两路输入

```text
宿主 user.md ── 章节词法选择 ──┐
                              ├─ 一个 # Memory 段 → 词元组装器
记忆后端 ── 当前查询 + 作用域 ─┘

当前工作状态 ── 独立字段 ───────→ 词元组装器
本会话历史 ──── 历史筛选 ──────→ 词元组装器
```

第一路是宿主长期背景，不是当前任务的五条笔记。`user.md` 按二级标题解析，查询词在标题的命中权重是正文的 3 倍。选择最多两个正分章节，加上 `Notes`，按原文件顺序展示；空查询、没有二级标题或没有任何选中章节时回退全文，仍受总词元预算限制。

第二路调用记忆后端，携带当前问题、用户及仓库范围，默认最多五条。本地默认后端是词法事实存储，不是默认部署的外部向量服务。两路统一由一个构建器合并和记录命中数，后端结果标记为未验证数据，不执行其中指令。

当前提示中的工作状态由 Curator 独立维护：最多 8 项目标、12 项未完成事项、20 项决策，每项最多 420 字符，随会话持久保存。快速路径也会加载它，不需要再次运行筛选模型。它不是第二路长期记忆召回。Worker 使用自己的会话命名空间；共享长期后端与客户端，不共享父任务的工作状态。

默认本地用户资料位于 `.pico/user_memory/profile/user.md`，其他用户采用独立的散列子目录。宿主读取检查工作区路径范围。不存在的资料允许为空；读取错误或已启用后端的硬错误会中止本轮，不伪装成无命中。宿主资料目前由调用者维护，已有后台笔记整理不等于自动刷新该资料。

## 外部记忆与可靠写入

配置 `[memory] base_url / api_key / timeout_seconds / extract_facts`，或使用 `--memory-url`、`--extract-facts`。环境变量支持 `GOPHERHARNESS_MEMORY_URL` 与 `GOPHERHARNESS_MEMORY_API_KEY`。不配置地址时继续使用本地后端。

外部服务必须实现本项目 Memory JSON v1 协议：`POST /v1/recall` 接收仓库、用户、查询和数量，响应必须回显相同作用域；`POST /v1/store` 接收本轮材料和轮次 ID，返回相同身份与 `durable: true` 才算成功。写入使用稳定 `Idempotency-Key`。不是 Mem0、Letta 或其他产品的开箱即用适配，服务端需实现此契约。

默认请求超时 30 秒，可配置 1～300 秒；响应上限 1 MiB，拒绝重定向转发密钥。除回环开发地址外要求 HTTPS。响应跨用户/跨仓库、格式错误或非持久回执均失败，不当作合法空召回或写入成功。

记忆写入先存本地 Outbox（待写记录），只有对应运行报告已提交为完成后才异步送到后端，不阻塞已完成答案。默认每次最长 30 秒、最多 5 次有界重试；关闭时取消并等待，未知写入保持持久待处理，恢复继续用同一轮次身份。后端应以幂等键去重，不能依靠客户端“只发一次”消除重复。

后台 dream（记忆整理）只读取同一用户拥有的会话和记忆，未标记用户的旧会话仅归本地用户；按用户保存结果。它不把不同群用户的私有历史拼在一起，也不自动更新宿主 `user.md`。

## 技能是常驻与检索两路，不是两路长期记忆

常驻技能由 `SKILL.md` 中的 `always: true` 标记决定，最多五份，独立于当前查询并排除出查询结果，防正文重复。

检索采用与参考算法相同的本地 BM25 Okapi：

- 索引文本 = 名称两次 + 描述一次 + 正文前 4,000 个字符。
- 英文按长度至少两位的字母数字串，中文按单个表意字；不是中文语义分词或向量检索。
- 词频饱和系数 1.5，长度归一化系数 0.75；预计算词频、文档频率、长度和平均长度。
- 逆文档频率 = log(1 + (文档总数 − 含词文档数 + 0.5) / (含词文档数 + 0.5))。
- 每词贡献 = 逆文档频率 × 词频 × 2.5 / (词频 + 1.5 × (0.25 + 0.75 × 文档长度 / 平均长度))。
- 当前一个本地源，先多取两倍即最多十个正分结果，再保留五个候选；单源倒数名次分不改变 BM25 排序，不冒充已接远端多源融合。

明确点名按技能名规范化匹配或有效名称词重合判定，最多注入两份完整正文；模糊相关或超出激活额度的候选只给引用。索引可看正文前 4,000 字符，引用相关性复核看名称、描述和正文前 2,000 字符。这些是检索边界，不是把已激活正文截断到该长度。

`skill_read` 只按注册名称读取缓存正文，不接受任意文件路径，不执行脚本或修改文件；仍受入口工具允许名单约束，飞书没有自动开放这个新工具。入口不允许该读取时，程序不向模型发布要求使用不可用工具的引用，仅记录未开放诊断。没有读取权限不能声称已读正文。主程序的权限、审批和工作区约束不因 BM25 得分提高而改变。

## 更新与失败

索引在发现后提前构建，查询只捕获元数据/索引快照并打分。调用时按 1 秒间隔懒刷新：重新发现文件、重建并原子替换快照，在途查询继续使用一致旧快照；不是后台文件监控或永久任务版本锁定。无效、删除或不可读技能从新目录移除，单份文件上限 1 MiB，拒绝越界符号链接。直接并发修改公开兼容字段 `Skills` 不受支持。

本地默认可加载用户技能、`.agents/skills` 和 `.pico/skills`，同名项目源覆盖用户源。`--no-personal-skills` 关闭个人目录；共享服务默认不加载个人技能，避免把启动账户的私有内容带进群聊。

空库、空查询、无正分不凑数；常驻技能独立保留。正文激活后不再统一截到 16,000 字节，完整词元门禁放不下就失败，避免半份操作步骤。读取技能、激活正文、执行其中步骤和完成验收是四件不同的事。

本地验证覆盖公式与权重、英文/中文、常驻去重、5/2/5 数量边界、引用读回、任意路径拒绝和并发快照替换。未调用收费模型，未做真实飞书验收。
